# BeeMedia 254 — Production & Visual Storytelling Platform

BeeMedia 254 is a modern, high-performance web platform built for a premier Kenyan photography and videography production agency. The website showcases signature portfolios, interactive production packages, corporate services, and a streamlined booking interface.

---

## Features

* **Interactive Production Packages:** Clear breakdown of pricing and gear specifications for Ruracio, Wedding, and Commercial shoots.
* **Filterable Media Portfolio:** Categorized showcase for Weddings, Commercial Campaigns, Events, Documentaries, and Birthdays.
* **Modern Glassmorphic UI:** Sleek dark-mode theme highlighted with golden-amber accents, smooth hover animations, and custom vector icons.
* **Direct Booking System:** User-friendly session booking form with dynamic service selection.
* **Fully Responsive:** Optimized for seamless performance across mobile, tablet, and desktop devices.

---

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling & UI:** Custom CSS (Flexbox & CSS Grid), Glassmorphism UI Effects
* **Icons & Fonts:** Font Awesome 6, Google Fonts
